# 机器狗程序使用说明 CUMCM 2026 B题 第四问

本目录是比赛用机器狗自动定位清除程序，共两个文件：

| 文件 | 作用                                                                                    |
|---|---------------------------------------------------------------------------------------|
| `robot_dog.py` | **比赛程序**。通过powershell连接官方模拟器，自动完成搜索、定位、清除干扰源并退出。                                      |
| `simulator.py` | **自建本地模拟器 + 验证工具**。在没有官方模拟器的情况下离线自测策略、批量跑蒙特卡洛用例。**它不是官方模拟器**，用于我们自己验证程序正确性及补充论文中所需数据。 |

运行环境：**Python 3.10 或更高版本，只用标准库**，不需要安装任何第三方包。Windows / macOS / Linux 都可以。

---

## 一、正式测试与演练测试


操作步骤：

1. 打开官方模拟器，登录参赛队账号。
2. 在界面里选择题目**4**，启动测试。
3. 测试启动后立刻在本目录下运行对应命令：

```bash
   python robot_dog.py --problem 4 --robot-id <参赛队号>
```

4. 程序运行结束后会打印一份 JSON 结果用于保存运行日志。


### 输出文件（在 `runs/` 子目录，自动创建）

每次运行产生一组同名前缀的文件：

- `q4-时间戳.json` —— 结果汇总：虚拟总时间、清除数、各阶段耗时、状态、错误信息等。
- `….jsonl` —— 全部 HTTP 请求/响应日志。
- `….decisions.jsonl`—— 每一步路径规划决策的详情，用于复盘。

> please pay attention to：`.jsonl` 是**我们程序自己记录的日志，不是官方的加密日志**。正式测试的有效日志以官方模拟器导出为准。

## 二、本地自测（自建模拟器，不碰官方平台）

`simulator.py` 内置了自建的、与官方题面要求相同的信号源模拟环境
### 单个用例

```bash
python simulator.py --problem 4 --scenario mixed --seed 20260912
```

输出 JSON 里的关键字段：

- `virtual_time_s`：总虚拟时间（评分依据，越小越好）。
- `cleared_count` / `source_count`：清除数 / 干扰源总数，相等即全清。
- `per_source_s`：平均每个源的耗时。
- `ok`：`true` 表示该例完整清除。

第 4 问可选场景：`mixed`（定向/全向各半）、`omni`（全全向）、`all_directional`（全定向）、`outward`（贴边朝外）、`tangent`（贴边切向）、`cluster`（中心聚集）。

`--sources N` 固定源数量（10–16，不填则随机），`--seed S` 控制随机种子（同种子结果完全可复现）。

### 批量验证（蒙特卡洛）

```bash
python simulator.py --problem 4 --bench --cases 6 --seed-base 2026092100
```
本地运行也会产生 `runs/` 下的日志文件，可随时删除。
